# Fcloude OS

Fcloude OS is a lightweight, fast, secure, and modern Linux distribution based on Arch Linux.

## Vision

Create an operating system suitable for:

- Students
- Schools
- Offices
- Developers
- Home users

Goals:

- Lightweight
- Secure
- Fast
- Beautiful UI
- Easy installation
- Modular editions
- Open Source
